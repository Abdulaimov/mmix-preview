# m.mix — демо-копия сайта для согласования

Статичная копия витрины интернет-магазина m.mix для просмотра дизайна: https://abdulaimov.github.io/mmix-preview/

Собирается из закрытого репозитория магазина командой `npm run export:preview`; вручную здесь ничего не правится. Цены временные, заказы, сметы и заявки мастеров из этой копии не отправляются. Сайт закрыт от поисковиков (noindex).
